# Envis 文档

欢迎使用 Envis 文档中心。

## 快速开始

1. 下载并安装 Envis。
2. 打开应用并创建你的第一个环境。
3. 在环境中添加所需服务并启动。

## 常见操作

### 创建环境

在 Envis 首页点击“新建环境”，输入环境名称后即可创建。

### 添加服务

进入某个环境后，点击“添加服务”，选择服务类型并填写配置。

### 导出配置

在环境详情页点击“导出配置”，可生成可分享的配置文件。
